# City assets

Selected original OBJ/MTL models and palette textures from Kenney:

- [City Kit (Commercial), version 2.1](https://kenney.nl/assets/city-kit-commercial)
- [City Kit (Roads), version 2.1](https://kenney.nl/assets/city-kit-roads)

Both packs are CC0 (public domain dedication). Original `License.txt` files
are retained in each pack directory. Geometry, material files and textures
are unmodified. The scene chooses and places a subset; no download is needed
at runtime. Asset coordinates are Y-up; the scene rotates them into Z-up and
scales road tiles to 8 metres. This is a stylized, low-poly test environment.

Models were downloaded from the above publisher pages on 2026-09-27.
